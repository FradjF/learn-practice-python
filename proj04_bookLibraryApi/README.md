#Book Library API

## Project overview
A Restful API for managing a personal book collection.

## Technology stack
- Python
- FastAPI
- SQLite
- SQLAlchemy
- Pytest
- Docker
- GitHub Actions

## Planned features
- Retrieve all books
- Retrieve a book by ID
- Create a book
- Update a book
- Delete a book

## Learning Objectives
- REST API development
- Database integration
- Automated testing
- Containerisation
- Continuous Integration
